# Culinary House — сайт кулинарной школы

Многостраничный сайт школы кулинарии и кондитерского искусства Culinary House (Ташкент) с AI-консультантом на Gemini.
Чистые HTML, CSS и JavaScript, без сборки. Сервер — Node.js без npm-зависимостей.

## Запуск

1. Скопируйте `.env.example` в `.env` и укажите ключ Gemini: `GEMINI_API_KEY=...`
   (получить ключ: https://aistudio.google.com/apikey).
2. Запустите `npm start` (нужен Node.js 18+).
3. Откройте http://localhost:5510.

Без ключа сайт работает полностью, а чат отвечает, что консультант временно недоступен, и предлагает контакты школы.
Сайт по-прежнему можно открыть и как статику (`index.html` или любой статический хостинг), но тогда чат работать не будет:
ему нужен сервер с `/api/chat`, чтобы ключ Gemini не попадал в браузер.

## AI-консультант (RAG)

База знаний — три документа в `rag/`: `price-list.md`, `faq.md`, `work-schedule.md`.
Консультант отвечает только по ним.

Как это работает:
1. При запуске сервер режет документы на фрагменты по заголовкам (`#`, `##`, `###`)
   и считает эмбеддинги через Gemini (`gemini-embedding-001`). Результат кэшируется в `rag/.index.json`
   и пересчитывается автоматически, если документы изменились (нужен перезапуск сервера).
2. На вопрос клиента сервер находит 6 самых близких фрагментов (косинусная близость) и передаёт их в Gemini
   (`gemini-3.8-flash`) вместе с системным промптом и последними сообщениями диалога.
3. Ответ приходит в чат потоком (SSE) с указанием документов-источников.

Если эмбеддинги недоступны, используется запасной поиск по ключевым словам.

| Файл | Назначение |
| --- | --- |
| `server/index.js` | HTTP-сервер: статика сайта, `POST /api/chat`, `GET /api/health`, лимит 20 запросов в минуту с IP |
| `server/rag.js` | Нарезка документов, эмбеддинги, кэш, поиск |
| `server/assistant.js` | Системный промпт и сборка запроса к модели |
| `server/gemini.js` | Вызовы Gemini API (эмбеддинги и потоковая генерация) |
| `js/assistant.js`, `css/assistant.css` | Виджет чата на всех страницах (RU/UZ, тёмная и светлая тема, мобильная версия) |

Настройки в `.env`: `GEMINI_API_KEY`, `GEMINI_MODEL`, `GEMINI_EMBED_MODEL`, `PORT`.
Проверить состояние: http://localhost:5510/api/health.

Для публикации нужен хостинг с Node.js (Render, Railway, VPS и т. п.): задайте переменную окружения `GEMINI_API_KEY`
и команду запуска `npm start`.

## Страницы

| Файл | Содержимое |
| --- | --- |
| `index.html` | Главная: все секции (hero, о школе, курсы, курс сезона, преподаватели, галерея, календарь, цены, доска почёта, отзывы, FAQ, запись) |
| `courses.html` | Все курсы с фильтром, курс сезона, FAQ |
| `teachers.html` | Преподаватели, доска почёта, отзывы |
| `gallery.html` | Галерея с фильтром по категориям и lightbox |
| `schedule.html` | Интерактивный календарь запусков курсов |

| `contacts.html` | Форма записи, контакты, карта |

## Структура

```
css/styles.css          темы (dark/light), компоненты, анимации, адаптив
js/data.js              контент: курсы, преподаватели, расписание, цены, отзывы, галерея, FAQ
js/i18n.js              тексты интерфейса на русском и узбекском
js/components.js        шаблоны шапки, подвала и всех секций
js/main.js              поведение: тема, язык, анимации, фильтры, календарь, карусель, форма
assets/img/placeholders локальные заглушки, если внешние фото недоступны
```

## Как редактировать

- **Тексты интерфейса:** `js/i18n.js` (объекты `ru` и `uz`).
- **Курсы, цены, преподаватели, отзывы, FAQ:** `js/data.js`. Поля с переводом заданы как `{ ru: "...", uz: "..." }`.
- **Фотографии:** URL-адреса собраны в `js/data.js` (объект `images`, поля `image` / `src`).
- **Преподаватели:** карточки без фото — инициалы строятся из имени автоматически, значок специализации задаётся полем `icon` (`chef`, `whisk`, `plate`, `cake`, `camera` — иконки в `js/components.js`).
  Чтобы использовать свои фото, положите файлы в `assets/img/` и укажите путь, например `"assets/img/hero.jpg"`.
  Фон hero задаётся в `css/styles.css` (селектор `.hero .parallax-bg`).
- **Расписание:** `launches` в `js/data.js`. Даты задаются смещением в днях от сегодняшнего дня (`offset`),
  поэтому календарь всегда показывает актуальные ближайшие старты. Чтобы зафиксировать конкретные даты,
  замените расчёт в `components.js` (функция `buildLaunches`).
- **Контакты:** объект `contacts` в `js/data.js` и строки `booking.*` в `js/i18n.js`.

## Форма записи

Бэкенда нет: заявка проверяется, сохраняется в `localStorage` (ключ `ch-bookings`) и показывается уведомление.
Чтобы отправлять заявки по-настоящему, замените функцию `CH.submitBooking` в `js/main.js`, например на запрос
к своему API или к Telegram Bot API через серверный прокси (токен бота нельзя хранить во фронтенде).

## Настройки пользователя

Выбранные язык (`ch-lang`) и тема (`ch-theme`) сохраняются в `localStorage` и применяются до отрисовки страницы.
